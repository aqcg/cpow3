## 1. 程式碼高亮與複製測試 (Python)

```python
# 測試 Python 程式碼高亮
def hello_developer(name):
    tools = ["ESP32", "Raspberry Pi", "Python"]
    print(f"Hello, {name}! 歡迎來到 VitePress。")
    print(f"目前開發設備：{', '.join(tools)}")

if __name__ == "__main__":
    hello_developer("Maker")
```
