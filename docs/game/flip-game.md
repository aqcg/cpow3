## 🎯 互動特色
- **動態軌跡畫布：** 滑動觸控即可繪製即時熄滅的光軌，每次觸發皆產生獨特的 HSL 鮮豔色彩。
- **自動波浪動畫：** 靜止時每 5 秒會自動觸發矩陣掃描與隨機脈衝燈效。
- **行動裝置優化：** 針對手機與平板觸控進行流暢度與防滑動延遲優化。
